# r100 개발 검증

포커스셀 설정은 선택 주변 6×5 표본과 옵션별 강조를 표시합니다. 포커스셀 메뉴 아이콘은 켜기/끄기와 같은 아이콘을 사용합니다. DLL 미리보기는 표본 격자와 전후 값을 표시하며, 원본 설명을 함께 제공합니다. 표본은 Excel 화면 전체를 그대로 재현한 화면이 아닙니다.

아래한글 그림 전송은 JPG·PNG·BMP를 문서에 포함한 셀 배경 그림으로 배치합니다. 기본 셀 크기는 7×6cm, 쪽당 가로 2개·세로 1개입니다. 제목행과 제목순/촬영시간순을 선택할 수 있습니다. 촬영시간은 EXIF DateTimeOriginal 기준이며 정보 없는 파일은 뒤쪽에 제목순으로 배치합니다. 기존 한글 전송용 내장 PowerShell 생성기를 사용하므로 단일 XLAM과 DLL 환경에서 같은 결과를 만듭니다.

생성·정렬·원본 보존·실제 Excel 검증과 한컴 렌더링 결과는 작업기록에서 구분합니다. 배포본은 별도 요청 시 생성합니다.
