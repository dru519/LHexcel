# 내엑셀 v0.01_r104 검증 및 배포

파일통합의 최대 20개 제한으로 발생하던 NX-346305 오류를 수정했습니다. 파일을 순차적으로 처리하며 기존 입력 검사와 데이터량 제한, 중단·복구 처리를 유지합니다.

파일 목록에 위·아래 이동, 전체 선택, Ctrl+A, Ctrl/Shift 다중 선택 및 선택 제거를 추가했습니다. 통합은 목록 전체를 위에서부터 처리합니다. 여러 파일을 이동할 때 상대 순서와 선택 상태를 유지합니다.

r103의 개인정보 검사, 기호표 단위, 아래한글 그림 제목칸·파일명 선택 개선을 포함합니다. 사용기한은 2027-12-31까지입니다. 내부망 단일 XLAM, DLL ZIP, EXE 설치파일을 동일 소스에서 생성합니다. DLL 패키지 README에 설치·연결 확인·제거 방법을 포함합니다.

서명과 조직 신뢰 승인 절차는 별도입니다. 네이티브 시험 통과 전 출시 완료로 표시하지 않습니다. 전자서명은 적용되지 않았습니다. 구체적인 검증 결과와 실제 설치·교체 범위는 해당 출시 기록을 확인하세요.
