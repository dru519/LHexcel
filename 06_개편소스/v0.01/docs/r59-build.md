# 내엑셀 v0.01_r59

매너 저장을 현재 통합문서의 A1/100% 원본 저장으로 정정한다. 원본 형식, 매크로, 메모와 사용자 내용을 제거하지 않는다. 숨김/차트 시트는 제외하고 새 문서는 Excel 기본 저장 창을 사용한다.

공개 분류는 14개, 기능/명령 항목은 178개다. 선택 시트들 파일로 저장은 삭제하고, 동일 실행 기능 6개는 단일 노출과 기존 ID 호환으로 통합한다. 시트/보기창/셀맞춤/수식/정보진단 재분류를 리본과 전체기능에 같이 반영한다.

파일 출력의 중복 완료 안내를 줄이고 비교 범위 및 제외 항목을 작업창에 표시한다. 내부망은 DLL 없이 VBA 기능을 사용하고, 고도화 배포는 NxHost32/64.dll을 추가한다.

서명은 사용자 결정에 따라 보류한다. 실제 검증 및 산출물 해시는 같은 출시 작업기록을 참조한다. CTP 탐색창 후보는 포함하지 않는다.
