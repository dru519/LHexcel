# 내엑셀 v0.01_r60

DLL 없이 열린 문서와 시트를 검색하고 이동하는 `문서·시트 탐색`을 보기창에 추가했습니다. 한 번 클릭하면 목록만 선택하며, Enter·더블클릭·이동 버튼으로 이동합니다. Esc 또는 닫기로 종료합니다. 통합문서 전환 시 탐색창이 뒤로 가려지는 문제와 입력 훅 정리를 보완했습니다.

내부망은 보호 XLAM 하나로 기본 기능을 사용합니다. 고도화 패키지는 동일 보호 XLAM과 NxHost32/64.dll을 포함합니다. 미완성 CTP 시험 후보는 포함하지 않습니다. 기존 매너 저장, 기능 분류, 셀 데이터 보호 및 복사/실행 취소 보호는 유지합니다.

## 알려진 제한 — 사용자 수용

- 탐색 목록을 클릭하기 전 첫 휠 입력이 반영되지 않을 수 있습니다. 원하는 목록을 한 번 클릭한 뒤 스크롤하세요.
- 내부망 조건부서식 포커스셀은 복사·붙여넣기·실행 취소 보호 중 강조 위치가 이전 위치에 머무를 수 있습니다. 셀 데이터 변경이나 실행 취소 손실을 허용한다는 뜻은 아닙니다.

배포 정책의 설정 파일 경로와 이전 경로 호환을 보완했습니다. 사용기한은 2027-06-29까지이며 2027-06-30부터 실행을 차단합니다.
