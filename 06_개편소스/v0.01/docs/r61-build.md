# 내엑셀 v0.01_r61

기능 구체화 1차 검토를 r60 문서·시트 탐색과 통합한 버전입니다. 메뉴 중복 정리, 저장·PDF·그림 삽입·폴더 및 파일 통합 흐름, 개인정보 점검과 파일 비교 결과를 보완합니다. 시트 이름 개별 편집, 원본을 변경하지 않는 역할 스타일 미리보기, 단축키 분류·검색과 설명을 제공합니다.

내부망은 보호 XLAM 하나로 공통 기능을 사용하며, 고도화 패키지는 같은 보호 XLAM과 NxHost32/64.dll을 포함합니다. 기존 r60 산출물과 설정은 덮어쓰지 않습니다. 미완성 CTP 후보와 제3자 코드·바이너리는 포함하지 않습니다.

## 남은 설계 범위

v3.4 전체 규칙형 파일명 작업대, 통합 템플릿 관리, 고유값 빈도 결과표와 데이터 도구 출력 위치 확장, AI 작업대 전체 재구성은 별도 후속 설계 대상입니다. 이번 구현을 이들의 전체 이식 완료로 취급하지 않습니다.

## 알려진 제한 — 사용자 수용

- 탐색 목록을 클릭하기 전 첫 휠 입력이 반영되지 않을 수 있습니다. 원하는 목록을 한 번 클릭한 뒤 스크롤하세요.
- 내부망 조건부서식 포커스셀은 복사·붙여넣기·실행 취소 보호 중 강조 위치가 이전 위치에 머무를 수 있습니다. 셀 데이터 변경이나 실행 취소 손실을 허용하는 것은 아닙니다.

사용기한은 2027-06-29까지이며 2027-06-30부터 실행을 차단합니다.
