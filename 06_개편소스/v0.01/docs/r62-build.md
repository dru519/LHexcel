# 내엑셀 v0.01_r62 후보

r61 기반 후속 구현입니다. 현재 문서는 빌드 입력용 설명이며 출시 또는 검증 완료 증거가 아닙니다.

## 변경 범위

- 템플릿, 단축키, AI는 각각의 독립 팝업을 유지하고 사용자 v3.4의 구성과 배치를 대응합니다. 하나의 범용 관리 작업대로 통합하지 않습니다.
- 데이터 전용 옵션과 결과 출력, 이름 변경 규칙과 복구, 비교 보고서의 원본 이동을 보완합니다.
- 실제 처리 결과에 맞춰 공개 기능명과 도움말을 다시 작성합니다. 남아 있는 기능은 기존 식별자를 유지합니다.
- 기본 Excel 중복 기능 44개는 실행 코드·계약에서 완전 제거합니다. 시트 복제의 숨김 경로까지 포함해 명령 44개와 외곽선 기능 1개의 등록을 제거하며, 표시형식 28개는 유지합니다.
- 그림 삽입과 선택 그림 맞춤은 한 팝업의 두 모드로 제공합니다. 맞춤의 실행·미리보기·복구 엔진은 삽입 엔진과 분리합니다.

내부망은 보호 XLAM으로 공통 기능을 사용하고, 고도화 패키지는 동일 보호 XLAM과 NxHost32/64.dll을 포함합니다. 기존 출시물은 덮어쓰지 않습니다. 미완성 CTP와 제3자 코드·바이너리는 포함하지 않습니다.

## 남은 검증과 제한

실제 Excel 컴파일, 변경 기능의 실행, 200% 환경 팝업 배치 및 DLL 설치 검증은 최종 출시기록의 개별 결과로 판정합니다. 정적 검사만으로 이를 통과했다고 보지 않습니다.

- v3.4의 구조 삽입 출력과 빈 인접 영역 출력은 다릅니다. 현재 인접 영역 출력은 행·열을 삽입하지 않습니다.
- AI는 로컬에서 요청을 만들고 클립보드로 복사합니다. 제공자 열기는 고정 주소만 열며 셀 내용이나 요청을 자동 전송하지 않습니다.
- 목록을 클릭하기 전 첫 휠 입력 누락과 내부망 조건부서식 포커스셀의 복사·붙여넣기/실행 취소 보호 중 갱신 유예는 사용자가 수용한 제한입니다. 데이터 보존 검증을 면제하지 않습니다.

사용기한은 2027-06-29까지이며 2027-06-30부터 실행을 차단합니다.

서명은 이번 범위에서 제외합니다. Authenticode/VBA signature는 NOT_RUN, 조직 신뢰 승인은 HOLD입니다. 최종 해시와 네이티브 증거는 같은 버전 출시기록을 확인하세요.
