# 내엑셀 v0.01_r64

r63 DLL HWPX 생성과 도킹 탐색창 구현을 통합한 후속 버전입니다.

- DLL 기능 찾기: 실제 Office 도킹창, 창별 검색·선택 보존, Windows DPI에 맞는 배치 및 대체창 전환.
- 내부망 XLAM: DLL 없이 공통 기능 사용. 조건부서식 포커스셀의 복사/Undo 갱신 유예는 기존 수용 범위.
- 고도화 설치: 사용자 계정 COM/XLSTART 등록. 기존 설치 제거 후 교체하고 사용자 설정을 보존.
- 내부망 반입 호환 B 패키지 순서, 배포 보호·이용 고지·설치 안내 유지.
- 사용기한 2027-06-29까지, 2027-06-30 차단.

서명은 이번 범위에서 제외합니다. 실제 검증 범위와 해시는 이 버전의 출시 기록을 기준으로 합니다.
Authenticode/VBA signature는 NOT_RUN, 조직 신뢰 승인은 HOLD입니다.
