# 내엑셀 v0.01_r66 구성 및 확인 범위

승인 범위: DLL 통합문서 비교의 성능·동등성, 실행계획/결과의 사용자 문구, 그림 기능 잔여 검증, 단일 XLAM·DLL ZIP·설치 EXE 3종 산출.

- DLL 비교: Excel에서 받은 문자열 DTO의 내부 저장만 연속 배열로 변경한다. 공개 COM 계약·한도·진행률·취소 주기·원본 보존은 유지한다.
- 비교 보고서: A:G를 텍스트로 먼저 지정한 뒤 한 행씩 일괄 기록한다. 비교 사유·값·수식 문자열·원본 이동 링크는 유지한다. 병합·서식 비교 및 DLL 없는 환경은 VBA가 처리한다.
- 실행 창: 기능과 분류를 사용자용 이름으로 표시한다. 실제 요청 범위를 표시하며 승인용 식별자와 파일 경로를 구분한다. 그림 성공 건수와 원래 실행 결과를 보존한다.
- 표 옵션의 기존 14개 입력/작업과 설명 배치를 유지하고 실제 배치·겹침 검사를 적용한다. 고정 치수를 단순히 줄이지 않는다.
- 여러 그림 선택은 Excel의 DrawingObjects 래퍼 주소 대신 그림의 소속 시트·ID·개수로 비교한다. 같은 선택인데 파일 선택기 복원 실패로 보고하는 문제를 수정했다.

## 설치와 검증 경계

단일 XLAM은 DLL 없이 사용한다. DLL ZIP과 EXE는 같은 기능에 DLL 탐색·그림 미리보기·비교 확장을 추가한다. 최초 설치 이후 Excel에서 자동 실행한다. 설치·연결 확인·기존 버전 교체·제거 안내는 DLL 패키지 README에 포함한다.

서명은 이번 범위에서 제외합니다. Authenticode/VBA signature는 NOT_RUN이며 조직 신뢰 승인은 HOLD입니다. x86 DLL 컴파일/순수 시험과 x86 Excel 실행 검증은 별개다. 현재 Windows 200%·x64 Excel 이외의 혼합 DPI·내부망 실반입 검증은 별도 대상이다. 조건부서식 포커스셀과 클릭 전 첫 휠 입력의 승인된 기존 제한은 유지한다.

기존 r65 산출물은 보존한다. 이번 버전의 실제 출시 여부·변경 소스·검증 결과·정확한 파일 해시는 프로젝트 작업기록 및 배포 검증 영수증에서 확인한다.
