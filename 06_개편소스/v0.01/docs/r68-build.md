# 내엑셀 v0.01_r68

표 그리기는 열린 표·9pt를 기본으로 사용합니다. 열린 표는 내부 격자와 위아래 바깥선을 유지하고 좌우 바깥선만 제거합니다. 마무리 옵션은 마지막 행의 서식 강조와 열 너비 맞춤의 적용 범위를 설명합니다. 미리보기는 선택 범위의 표본이며 열 너비 자동 맞춤은 추정값입니다.

선택 범위 그림 저장은 현재 문서 폴더에 PNG를 바로 저장합니다. 아직 저장하지 않은 문서는 Excel 기본 저장 폴더를 사용합니다. 파일명에는 문서·시트·범위·시간을 넣고 같은 이름이 있으면 번호를 붙입니다. 오류가 있을 때만 안내합니다.

스타일의 빠른 서식은 글씨 크기 9/10/12/15, 글씨색 검정/빨강/파랑/초록, 셀색 회색/연한빨강/연한노랑/연한초록을 아이콘으로 제공합니다. 지정한 속성만 적용합니다.

단축키 관리에서 조합을 직접 입력하거나 눌러 등록할 수 있습니다. Excel과 Windows의 확인된 기본키는 등록할 수 없습니다.

모형병합은 현재 가로 방향 전용입니다. 실제 셀을 합치지 않고 세로로 이어진 셀의 중앙에 값을 표시하는 기능은 이번 버전에 포함하지 않습니다. 표 미리보기의 병합 범위는 분리 격자 표본으로 표시되며 화면에 해당 한계를 안내합니다.

실행 대상과 원본 상태의 확인 비용을 줄였으며 원본 변동 확인·오류 복구는 유지합니다. 실제 성능과 출력 검증은 프로젝트의 r68 작업기록과 검증 영수증을 따릅니다.

## 배포 및 설치

단일 XLAM / DLL ZIP / 설치 EXE를 병행합니다. DLL ZIP의 README에 설치·연결 확인·제거 절차를 포함하며 설치 이후 Excel에서 자동 실행합니다. 무서명 배포이며 인증·조직 신뢰 승인, Office x86 및 혼합 DPI는 별도 확인 대상입니다.
