# 내엑셀 v0.01_r69

실행 버튼에서 현재 옵션을 검증한 뒤 즉시 처리합니다. 공통 계획 확인창과 일반 완료창은 표시하지 않습니다. 파일 덮어쓰기 및 템플릿 삭제의 구체적 확인은 유지합니다.

날짜/생년월일 변환과 만 나이는 오른쪽 새 열 삽입(기본), 원본 변경, 새 시트, 새 통합문서로 결과 위치를 선택합니다. 만 나이는 별도 창에서 기준일, 앞의 ‘만’, 뒤의 ‘세’를 선택합니다. 빈 셀은 제외하고 변환 불가 값은 빈칸으로 둡니다.

선택범위 사본 저장은 폴더를 고른 후 바로 저장하고 폴더 열기·파일 열기·닫기를 제공합니다. 선택범위 그림은 폴더·이름·PNG/JPG 확장자를 지정합니다.

통합문서 비교는 저장하지 않은 새 보고서를 엽니다. 요약·셀 차이·양쪽 원본 링크·표시 형식·병합 범위를 제공합니다. 최종 저장은 사용자가 결정합니다.

빌드·정적 검사·실제 Excel 검증 및 배포 상태는 r69 작업기록에 따릅니다. DLL ZIP에는 설치·연결 확인·제거 안내를 포함합니다. 기존 배포본은 덮어쓰지 않습니다.

서명은 이번 범위에서 제외합니다. Authenticode/VBA signature는 NOT_RUN, 조직 신뢰 승인은 HOLD입니다.

셀 편집 중 커서 위치에 계산결과·기호를 직접 넣는 기능은 보류입니다. 편집 내용을 강제로 확정하지 않으며, 현재는 복사한 결과를 원하는 편집 위치에 Ctrl+V로 붙여넣습니다.
