# 내엑셀 v0.01_r70

50열 × 1800행의 표 그리기와 선택범위 사본 저장 성능을 개선하는 검증 후보입니다. 원본 전체 상태 검사는 유지하면서 중복 조회와 복구 기록의 메모리 사용을 줄입니다. 실제 개선 수치는 Excel 측정 결과가 확보된 뒤 작업기록에 기록합니다.

백분율·천 단위·소수점 컨트롤 오른쪽에 Excel 기본 왼쪽·가운데·오른쪽 정렬 버튼을 배치합니다.

r69의 직접 실행, 데이터 결과 위치, 저장되지 않은 비교 보고서 흐름을 유지합니다. 파일 덮어쓰기와 템플릿 삭제 확인은 유지합니다.

빌드 성공, Excel 실행·오류 복구, 9만 셀 측정, 설치·배포 검증은 서로 구분합니다. 검증 전 출시 완료로 간주하지 않습니다. 기존 완성본과 배포본은 덮어쓰지 않습니다.

DLL ZIP에는 설치·연결 확인·제거 안내를 포함합니다. 서명은 이번 범위에서 제외하며 Authenticode/VBA signature는 NOT_RUN, 조직 신뢰 승인은 HOLD입니다.
