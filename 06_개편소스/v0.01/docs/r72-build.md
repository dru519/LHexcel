# 내엑셀 v0.01_r72 성능 개선 후보

셀별 테두리 복구 정보를 보존하면서 반복 객체 조회와 속성명 생성을 줄입니다. 범위 전체의 테두리 조회로 셀별 상태를 대체하지 않습니다.

표 그리기의 제목행 아래와 마지막 행 아래는 굵은 실선으로 표시합니다. 열린 표는 좌우 바깥선만 없애고, 닫힌 표는 바깥선을 유지합니다. 아래한글 표 전송은 범위 선택 후 바로 전송하며 취소 시 출력하지 않습니다.

실행·복구·성능·패키지 검증 결과는 프로젝트 작업기록을 따릅니다. 네이티브 시험 통과 전 출시 완료로 표시하지 않습니다. DLL ZIP에는 설치·연결 확인·제거 안내를 포함합니다.

서명과 조직 신뢰 승인 절차는 별도입니다.
