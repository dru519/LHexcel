# 내엑셀 v0.01_r74

기능 정리: 지정 기능 삭제, 빠른 서식 리본 전용, 시트·보기 통합, 화면 프리셋 메뉴. 숫자 강조(▲▼), 셀수식 메모 표시 선택, 현재 폴더 새 창 열기.

두 실행 프로필은 internal-xlam / enhanced-dll이며, 단일 XLAM·DLL ZIP·EXE를 별도 폴더로 산출한다. DLL ZIP은 설치 안내를 포함한다.

서명과 조직 신뢰 승인 절차는 별도입니다.
실제 보안제품 격리 복구 검증은 NOT_RUN. 배포 전 소스·패키지 해시와 변경 기능 Windows Excel 검증이 필요하다.

네이티브 시험 통과 전 출시 완료로 표시하지 않습니다.
