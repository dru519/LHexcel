# 내엑셀 v0.01_r77

서명과 조직 신뢰 승인 절차는 별도입니다.
네이티브 시험 통과 전 출시 완료로 표시하지 않습니다.

이번 산출 범위는 완성본입니다. 기존 r76 배포본은 보존합니다.
정규화 미리보기는 범위 전체의 수식 여부를 먼저 확인하고, 혼합 범위만
셀별로 판별합니다. 표 구조 정리는 병합이 없는 범위에서 병합 조회를 생략합니다.
병합이 포함된 범위는 기존 대표값 전개 처리를 유지합니다.

성능 수치는 동일한 Windows Excel에서 r76과 r77의 2만 셀 시험을 비교합니다.
수식·오류·빈칸·병합 및 결과 시트 생성 검증을 함께 수행합니다.
전체 기능의 속도 개선이나 설치 검증 완료를 의미하지 않습니다.
