# 내엑셀 v0.01_r91

아래한글 표 전송의 제목행 아래를 공문형·간결형 모두 이중 실선으로 맞췄습니다.
전송 결과 텍스트 양끝의 공백·탭·줄바꿈 없는 공백·전각 공백을 제거합니다.
문장 내부의 띄어쓰기와 줄바꿈, 원본 Excel 값은 유지합니다.
데이터 메뉴 첫 항목에 데이터 비교(범위·시트·파일)를 배치합니다.

포커스셀은 r90의 시트 재계산 방식과 복사·Undo 보호 중 갱신 보류를 유지합니다.
수동 계산 모드에서도 활성 시트의 수식이 갱신될 수 있습니다.
사용기한 2027-12-31, 차단 시작 2028-01-01. 서명 및 32비트 Excel 실기 검증은 별도입니다.
