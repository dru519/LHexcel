# 내엑셀 v0.01_r94

템플릿 보관함: 검색·분류·사용자 순서/이름/수정일/최근사용 정렬, 상세 편집,
현재 문서 새 시트 또는 새 통합문서로 사용.
엑셀파일 등록·엑셀시트 등록·위로·아래로·삭제는 목록 오른쪽에 세로 배치한다.
양식 이름·분류·등록 방식·수정일을 표로 표시하고 열 경계를 드래그해 조절한다.
삭제 항목 보기 및 문서 등록 버튼은 제공하지 않는다.
저장소는 설치 폴더 아래 내엑셀 템플릿으로 자동 지정한다.
등록은 별도 팝업이며 미리보기 없이 실행할 수 있다.

목록은 메타데이터만 읽으며 실제 사용·복원 시 선택 패키지의 해시와 내용을 검사한다.
기존 메타데이터 v1은 계속 읽고 수정 시 v2로 저장한다. 변경 전 메타데이터는
저장소 Backups에 보존한다. 최근 사용 기록 실패는 만들어진 결과를 폐기하지 않는다.

완성본 및 배포본 검증 범위는 작업 기록을 따른다. 단일 XLAM·DLL ZIP·EXE를 생성하며 메일은 발송하지 않는다.
