# 내엑셀 v0.01_r97

이전 설치 기록은 버전별로 선택해 복구 보관 폴더로 정리할 수 있습니다.
설치 캐시 포함 여부를 선택하며 현재 버전·사용자 설정·제거 미확인 기록은 보존합니다.
같은 r97의 수정된 패키지는 업데이트로 적용합니다. 등록 충돌 시 해당 경로를 표시합니다.

설치 시작 안내 → 다음 → 설치 위치·변경 내용 확인 → 설치 → 진행 → 마침 순서로 화면을 구성했습니다.
이미 설치된 경우 업데이트·복구·제거·상태 확인 중 작업을 선택합니다.
제거는 대상 버전과 위치를 확인한 뒤 시작하며 완료 화면에서 마침으로 종료합니다.
상태 확인 후에는 설치 관리로 돌아가 다른 작업을 선택합니다.
이전 설치 기록은 전체 선택·전체 해제와 선택 개수 표시를 지원합니다.
설치 완료 화면의 Excel 실행 항목을 선택한 뒤 마침을 누르면 Excel을 시작합니다.
상세 로그는 기본으로 접고 필요할 때 펼칩니다. 실패하면 원인을 확인하고 다시 시도할 수 있습니다.
제어판과 설치 EXE는 같은 제거 절차를 사용하며 결과를 화면에 표시합니다.

그림 미리보기는 FIT/ORIGINAL 배치 비교, 크기와 여백, 셀 밖 영역을 표시합니다.
보기 전환은 실제 삽입 설정을 바꾸지 않습니다.
표 그리기 미리보기는 표본 범위의 병합만 확인하고 중복 옵션 갱신을 줄입니다.

미리보기는 선택 사항입니다. 사용기한은 2027-12-31입니다.
기존 r97의 설치·제거와 실제 Excel 연결은 확인했습니다. 단계형 설치 UI 수정본의 실제 EXE 수용 검증은 별도로 진행합니다. 전자서명은 적용하지 않았습니다.
