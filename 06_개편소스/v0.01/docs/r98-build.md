# 내엑셀 v0.01_r98

설치 시작 안내에서 다음을 누르고, 설치 위치와 변경 내용을 확인한 뒤 설치합니다.
설치된 경우 업데이트·복구·제거·상태 확인을 선택합니다. 완료 화면에서 Excel 실행 여부를 선택할 수 있습니다.

제거는 대상 버전과 위치를 확인한 뒤 실행합니다. 이미 제거된 경우 별도 안내를 표시합니다.
상태 확인 후 설치 관리로 돌아갈 수 있으며 이전 기록의 전체 선택·전체 해제·선택 개수를 지원합니다.
사용자 설정은 업데이트·제거 시 보관합니다. 제거 완료된 과거 기록은 선택해서 복구 보관 폴더로 옮깁니다.
설치 로그는 필요할 때 펼쳐 확인할 수 있습니다. 긴 경로와 결과는 스크롤해서 확인합니다.

단일 XLAM은 DLL 없이 사용하고, DLL ZIP과 EXE는 고도화 기능을 포함합니다.
내부망 포커스셀은 이번 변경 대상이 아닙니다. 사용기한은 2027-12-31입니다.
전자서명은 적용하지 않았습니다. 검증 결과와 지원 범위는 함께 제공한 출시 기록을 참고하세요.
