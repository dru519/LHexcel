# LHexcel 내엑셀

내엑셀은 **외부 AI 서비스에 연결하지 않고, 윈도우 내부망에서도 반복 업무를 줄이도록 만든 Excel 추가 기능**입니다. 표를 그리고 자료를 비교하거나, 아래한글로 표와 그림을 옮기고 여러 파일을 정리하는 등 업무에서 자주 쓰는 편의기능을 한곳에 담았습니다.

같은 모양의 표를 다시 만들고, 지난주 자료와 이번 주 자료를 대조하고, 사진을 보고서에 하나씩 배치하는 작업은 작은 일이지만 반복되면 시간이 많이 듭니다. 내엑셀은 이런 작업의 준비와 정리를 덜어 주어, 자료의 내용과 결과를 살피는 데 더 집중할 수 있도록 만들었습니다.

**표 작성·자료 비교·파일 관리 등 주요 업무 기능은 AI 계정이나 API 연결 없이 사용합니다.** 선택 기능인 AI 작업대도 AI 서비스와 직접 연결하지 않습니다. 요청문을 복사해 사용자가 각 AI 서비스의 채팅창에 직접 붙여넣는 방식입니다.

내엑셀은 **소스 공개 소프트웨어**이며, 이용 조건은 [LICENSE](LICENSE)를 따릅니다.

개인·기업·공공기관의 일반 업무 사용은 무료입니다. 프로그램·소스의 판매, 유료 재배포, 상품화 및 유료 제품·서비스 포함은 금지합니다. 원본 무료 공유에는 출처와 이용 조건을 유지해야 하며, 수정본의 외부 배포에는 별도 허락이 필요합니다.

내엑셀의 업무 흐름은 [소개 카드뉴스 8장](introduction/README.md)에서도 볼 수 있습니다.

|---|---|---|
| 내려받은 자료가 지난주와 어떻게 달라졌는지 확인 | 범위 비교 · 시트 비교 · 파일 비교 | 차이를 별도 결과로 확인합니다. 시트·파일 비교는 차이 목록과 이동 링크를 제공합니다. |
| 엑셀에서 정리한 표를 아래한글 보고서에 사용 | 아래한글 표 전송 | 선택한 셀 범위를 글꼴·글자 크기·표 모양 설정에 맞춰 아래한글 표로 전달합니다. |
| 사진과 그림을 아래한글 보고서에 가지런히 배치 | 아래한글 그림 전송 | 여러 그림을 표의 셀 배경에 넣고, 그림 크기·쪽당 배치·제목행·정렬 순서를 지정합니다. |

| 엑셀에 적어 둔 목록대로 폴더 만들기 | 폴더 일괄 생성 | 한 행을 하나의 폴더 경로로 읽어 상위·하위 폴더를 만듭니다. |

| 필터로 보이는 자료만 복사하거나 입력 | 보이는 셀만 복사 · 보이는 셀에 값·수식·서식 붙여넣기 | 숨김·필터로 가려진 셀을 제외하고 값·수식·서식을 작업합니다. |
| 명단의 중복과 항목별 건수 확인 | 중복 목록 · 고유값 개수 | 두 목록의 공통·차이 항목을 찾고, 값별 등장 횟수와 비율을 계산합니다. |

| 개인정보가 들어 있는 자료 점검 | 개인정보 의심 항목 점검 · 개인정보 마스킹 | 의심 패턴의 위치를 찾고, 선택한 유형의 일부 문자를 가립니다. |
| 필요한 부분만 저장하고 출력 준비 | 사본 저장 · PDF 저장 · 그림 저장 · 인쇄 설정 | 현재 시트나 선택 범위를 별도 파일로 저장하고, 용지 방향·배율·반복 제목행을 설정합니다. |
| 열린 문서와 자주 쓰는 기능을 쉽게 찾기 | 문서·시트 탐색 · 포커스셀 · 즐겨찾기 · 단축키 · 템플릿 | 작업 위치를 찾고, 자주 쓰는 기능과 업무 양식을 가까이 둡니다. |
| 수식 확인과 간단한 입력 보조 | 셀수식 메모 기록 · 수식 참조표 · ROUND·IFERROR 감싸기 · 계산기 · 기호표 | 수식을 확인·정리하고 계산 결과나 기호를 셀에 입력합니다. |

위 표는 대표 기능입니다. Excel의 **내엑셀 탭 → 전체기능** 또는 **탐색창**에서 기능을 찾아 실행할 수 있습니다.

## 다운로드와 사용 환경

[공식 Releases](https://github.com/dru519/LHexcel/releases)에서 사용할 형식 한 가지를 내려받으세요. 현재 기능 기준은 **v0.01_r105**, 공식 배포본의 사용기한은 **2027-12-31**입니다. 파일별 SHA-256은 릴리스와 [배포 파일 정보](RELEASE_ASSETS.json)에 있습니다.

| 배포 형식 | 파일 | 선택 기준 |
|---|---|---|
| XLAM 단독형 | `LHexcel_v0.01_r105.xlam` | 별도 DLL·EXE 설치 없이 사용합니다. EXE 반입이 제한된 내부망에서 선택할 수 있습니다. |
| EXE 설치형 | `LHexcel_v0.01_r105_Setup.exe` | XLAM과 자체 DLL, 설치·업데이트·복구·제거 도구를 함께 설치합니다. |

DLL ZIP을 별도로 내려받을 필요는 없습니다. EXE에 필요한 내부 패키지가 포함되어 있습니다. 두 형식을 동시에 활성화하지 말고, 사용 환경에 맞는 한 가지를 선택하세요.

| 환경 | 안내 |
|---|---|
| 실행 환경 | 이 저장소의 XLAM·EXE 배포본은 Windows Excel용입니다. |
| EXE 설치형의 Excel 비트수 | x86·x64 Excel을 대상으로 합니다. 네이티브 ARM64·ARM64EC Excel은 지원하지 않습니다. |
| 아래한글 전송 결과 | 생성된 문서를 열고 편집하려면 아래한글이 필요합니다. |
| 내부망 | 주요 업무 기능은 AI 연결 없이 사용합니다. 파일 반입과 매크로·프로그램 실행은 소속 조직의 허용 절차를 따르세요. |

XLAM 단독형과 EXE 설치형은 같은 기능 기준을 사용하며, 일부 화면과 실행 방식에 차이가 있습니다. 예를 들어 포커스셀은 XLAM 단독형에서 조건부서식으로, DLL 환경에서 오버레이로 표시합니다. EXE 설치형의 문서 비교와 아래한글 표·그림 전송에는 DLL 연결이 필요합니다.

## 설치하기

### XLAM 단독형

1. `LHexcel_v0.01_r105.xlam`을 Windows 로컬의 계속 보관할 폴더에 저장합니다. 작업 중인 Excel 문서도 저장하세요.
2. Excel에서 **파일 → 옵션 → 추가 기능**을 엽니다.
3. 아래의 **관리: Excel 추가 기능 → 이동 → 찾아보기**에서 내려받은 XLAM을 선택합니다.
4. 추가 기능 목록에서 내엑셀을 체크하고 Excel을 다시 실행합니다.
5. 리본의 **내엑셀** 탭과 메뉴를 확인합니다.

### EXE 설치형

1. 작업 중인 문서를 저장하고 Excel을 모두 종료합니다.
2. `LHexcel_v0.01_r105_Setup.exe`를 실행합니다. 설치 화면에 표시된 작업과 대상을 확인한 뒤 진행하세요.
3. 설치 완료 화면의 **Excel 실행**을 누르거나 Excel을 직접 다시 실행합니다.
4. **파일 → 옵션 → 추가 기능 → 관리: COM 추가 기능 → 이동**에서 **내엑셀 NxHost** 연결을 확인합니다.
5. 문서 비교나 아래한글 전송 등 필요한 기능을 실행하여 연결을 확인합니다.

기존 설치가 있으면 설치 화면의 업데이트·복구 기능을 사용하세요. 설치 경로, 매크로 차단, 기존 버전과의 충돌, 제거 방법은 [XLAM·EXE 설치 안내](INSTALLING.md)에 정리되어 있습니다. 내부 DLL 패키지의 수동 복구가 필요한 경우에는 [DLL 설치 안내](source/v0.01/docs/dll-install-guide.md)를 참고하세요.

## 처음 사용하는 순서

1. 작업할 Excel 문서를 열고, 먼저 사본이나 간단한 자료로 필요한 기능을 확인합니다.
2. 셀을 대상으로 하는 기능은 작업할 범위를 선택합니다. 파일이나 그림을 대상으로 하는 기능은 실행 화면에서 대상을 고릅니다.
3. **내엑셀 탭**, **전체기능**, **탐색창**에서 기능을 실행합니다. 홈 탭의 내엑셀 메뉴에서도 기능을 찾을 수 있습니다.
4. 대상·옵션·결과 위치를 확인합니다. 미리보기가 있는 기능은 예정 결과를 확인한 뒤 적용하세요.
5. 결과를 확인하고 저장합니다. 새 결과 문서를 만드는 기능과 현재 문서를 수정하는 기능을 구분하세요.

자주 쓰는 기능은 즐겨찾기에 두거나 단축키 관리에서 지정할 수 있습니다. 업무 양식은 템플릿에 등록해 찾아 사용할 수 있습니다.

## 자주 쓰는 기능의 사용법

### 표 그리기

자료는 정리했지만 테두리와 제목행 서식을 매번 맞추기 번거로울 때 사용합니다.

1. 표로 꾸밀 셀 범위를 선택하고 **표 그리기**를 실행합니다.
2. 범위를 확인하고 표 유형, 제목행, 제목·내용의 글자 크기와 정렬을 지정합니다.
3. 미리보기에서 모양을 확인합니다. 미리보기는 최대 5×5 셀 표본입니다.
4. **적용**을 눌러 선택 범위의 서식을 바꿉니다. 기본 동작은 셀의 값과 수식을 유지합니다.

제목 부분만 꾸미려면 **타이틀표 그리기**, 제목·본문·합계 등 역할에 맞는 서식을 선택하려면 **내엑셀 스타일**을 사용하세요.

### 범위·시트·파일 비교

내부망에서 내려받은 지난주 자료와 이번 주 자료의 차이를 확인할 때 사용합니다.

| 비교할 대상 | 선택할 기능 | 비교 기준 |
|---|---|---|
| 두 셀 영역 | 범위 비교 | 두 범위의 왼쪽 위 셀을 맞춰 비교합니다. |
| 두 워크시트 | 시트 비교 | 같은 셀 주소의 내용을 비교합니다. |
| 두 Excel 파일 | 파일 비교 | 기준·비교 파일과 시트 쌍을 지정하여 비교합니다. |

파일 비교는 다음 순서로 사용합니다.

1. **파일 비교**를 실행하고 기준 파일과 비교 파일을 선택합니다.
2. 비교할 기준 시트와 비교 시트를 지정합니다.
3. 표시 형식 비교 등 필요한 옵션과 결과 위치를 확인합니다.
4. **비교**를 실행하고 기준·비교 사본과 차이 목록을 확인합니다.
5. 차이 목록의 이동 링크로 해당 셀을 확인하고, 필요한 결과를 저장합니다.

비교 대상 원본은 변경하지 않습니다. 행 순서가 달라진 자료는 같은 위치에 다른 항목이 놓일 수 있으므로, 비교 기준에 맞게 정렬하거나 범위를 맞춘 뒤 사용하세요.

### 아래한글 표 전송

엑셀에서 정리한 표를 아래한글 보고서에 사용할 때 적용합니다.

1. 전송할 셀 범위를 선택합니다.
2. 필요하면 아래한글 표 설정에서 글꼴·글자 크기·표 모양·제목행·숨김 행과 열의 포함 여부를 지정합니다.
3. **아래한글 표 전송**을 실행합니다.
4. 생성된 문서를 아래한글에서 열어 표의 너비, 줄바꿈과 페이지 배치를 확인합니다.

기본 글꼴은 중고딕, 기본 글자 크기는 13pt입니다. 전송해도 원본 Excel 셀은 유지합니다. EXE 설치형에서는 해당 기능의 DLL 연결을 확인하세요.

### 아래한글 그림 전송

현장사진이나 그림 파일을 아래한글 표의 셀 배경에 넣어 정리할 때 사용합니다.

1. **아래한글 그림 전송**을 실행하고 그림 파일을 선택합니다.
2. 그림 셀의 가로·세로 크기와 한 쪽에 배치할 가로·세로 개수를 지정합니다.
3. 그림 순서를 제목순 또는 촬영시간순으로 정하고, 제목행이나 파일명 표시가 필요하면 선택합니다.
4. **전송**을 누르고 생성된 문서의 그림 배치를 확인합니다.

그림은 문서에 포함됩니다. 촬영시간 정렬은 EXIF 정보를 사용하며, 촬영시간 정보가 없는 그림은 뒤쪽에 제목순으로 배치합니다.

### 폴더 일괄 생성

엑셀에 정리한 사업명·현장명·자료 구분대로 폴더를 만들 때 사용합니다.

1. 폴더 이름을 셀에 적습니다. 한 행이 하나의 경로이며, 왼쪽 열부터 상위 → 하위 폴더 순서입니다.
2. 제목행을 제외한 범위를 선택하고 **폴더 일괄 생성**을 실행합니다.
3. 기준 폴더와 선택 범위를 확인합니다. 필요하면 각 폴더 이름 앞뒤에 붙일 문구를 지정합니다.
4. **미리보기**에서 경로를 확인한 뒤 **생성**을 누릅니다.

예를 들어 기준 폴더가 `C:\업무자료`이고 아래 두 행을 선택하면 다음 경로를 만듭니다.

| 상위 폴더 | 하위 폴더 | 생성 경로 |
|---|---|---|
| 사업A | 현장사진 | `C:\업무자료\사업A\현장사진` |
| 사업A | 계약서 | `C:\업무자료\사업A\계약서` |

한 열만 선택하면 같은 기준 폴더 아래에 여러 폴더를 만듭니다. 현재 화면의 제한은 최대 500행·생성 폴더 500개입니다.

### 파일 이름 일괄 변경

여러 파일의 이름을 일정한 규칙으로 맞출 때 사용합니다.

1. **파일 이름 일괄 변경**을 실행하고 대상 파일을 추가합니다.
2. 화면에서 이름 변경 규칙과 옵션을 지정합니다.
3. 예정 이름과 충돌 여부를 확인합니다.
4. 실행 후 결과를 확인합니다. 마지막 이름 변경은 제공되는 복구 기능으로 되돌릴 수 있습니다.

### 파일 통합

여러 담당자나 현장에서 받은 Excel 파일을 한 파일로 모을 때 사용합니다.

1. **파일 통합**을 실행하고 파일을 추가합니다. Ctrl·Shift로 여러 파일을 선택할 수 있습니다.
2. 위·아래 이동 버튼으로 파일 순서를 정하고 저장 폴더와 이름을 지정합니다.
3. 한 시트로 이어 붙이기, 시트별로 모으기, 두 결과 모두 만들기 중 필요한 방식을 선택합니다.
4. 제목행 처리와 목차 등 옵션을 정하고 **미리보기**로 구성을 확인합니다.
5. **통합**을 실행하고 새 결과 파일을 확인합니다.

보이는 시트를 파일·시트 순서대로 처리합니다. 한 시트로 이어 붙일 때는 열 수가 같아야 합니다. 첫 행이 같은 제목행이면 첫 시트의 제목행만 유지하는 옵션을 사용할 수 있습니다. 시트별 결과에는 목차를 만들고 각 시트와 오가는 링크를 넣을 수 있습니다.

### 보이는 셀만 복사·붙여넣기

필터나 숨김이 적용된 자료에서 화면에 보이는 셀만 작업할 때 사용합니다.

1. 원본 범위를 선택하고 **보이는 셀만 복사**를 실행합니다.
2. 붙여넣을 대상 범위를 선택하고, 대상의 보이는 셀 수와 복사한 자료의 크기를 확인합니다.
3. **보이는 셀에 값 붙여넣기**를 실행합니다. 숨김 셀은 건너뜁니다.

수식과 서식은 각각 **보이는 셀에 수식 붙여넣기**, **보이는 셀에 서식 붙여넣기**를 사용합니다. 이 경우에는 Excel 형식의 클립보드와 복사 범위 구성을 확인하세요.

### 필요한 부분만 저장·인쇄하기

**현재 시트 사본 저장**이나 **선택 범위 사본 저장**으로 공유할 부분만 새 Excel 파일로 만들 수 있습니다. **현재 시트 PDF 저장**, **문서 PDF 저장**, **선택 범위 그림 저장**도 제공합니다.

인쇄할 범위를 선택하고 용지 방향과 너비 1쪽·한 장에 맞춤 옵션을 지정하세요. 여러 페이지에 제목행을 반복하려면 **선택 행을 인쇄 제목으로**를 사용합니다. **선택 범위 인쇄 미리보기**에서 배치를 확인한 뒤 출력하세요.

## AI 작업대의 사용 방식

AI 작업대는 주요 업무 기능과 별도로 선택해 사용하는 요청문 작성 보조 기능입니다. **AI API를 호출하거나 요청을 자동 전송하지 않습니다.**

요청 내용을 구성한 뒤 클립보드로 복사하고, 사용자가 AI 서비스의 채팅창에 직접 붙여넣어 전송합니다. 복사 후 선택한 AI 서비스의 웹사이트를 여는 동작이 있으며, 서비스 접속과 이용에는 해당 환경의 네트워크와 계정이 필요합니다.

외부 AI에 접속할 수 없는 내부망에서는 AI 작업대를 사용하지 않아도 표 그리기, 자료 비교, 아래한글 전송과 파일 관리 등 주요 업무 기능을 사용할 수 있습니다. 업무 자료를 외부 서비스에 붙여넣을 때는 자료의 권한과 소속 조직의 정보보안 정책을 확인하세요.

## 사용 중 확인할 사항

| 상황 | 확인할 내용 |
|---|---|
| 내엑셀 탭이 보이지 않음 | Excel 추가 기능 목록의 활성화 상태를 확인하고 Excel을 다시 실행하세요. EXE 설치형은 COM 추가 기능의 내엑셀 NxHost 연결도 확인합니다. |
| 다운로드한 XLAM의 매크로가 차단됨 | 소속 조직의 허용 절차를 확인하세요. 허용되는 경우에만 파일 속성의 차단 해제를 적용하며, 매크로 보안을 일괄 해제하지 마세요. |
| EXE 설치형의 문서 비교·아래한글 전송이 실행되지 않음 | DLL 연결과 버전을 확인하고 같은 설치파일의 복구 기능을 사용하세요. DLL 한 개만 다른 버전으로 교체하지 마세요. |
| 비교 결과에 예상보다 많은 차이가 표시됨 | 범위 시작 위치, 시트 쌍, 행·열 순서와 비교 옵션을 확인하세요. |
| 큰 범위를 한 장에 인쇄하면 글자가 작아짐 | 한 장에 맞춤 대신 너비 1쪽을 사용하고 인쇄 미리보기를 확인하세요. |
| 중요한 원본에 서식·값 변경 기능을 적용함 | 원본이나 사본을 먼저 보존하고, 기능별 결과 위치와 복구 안내를 확인하세요. 모든 기능이 Excel의 기본 실행 취소와 같지는 않습니다. |

제거 방법은 [설치 안내](INSTALLING.md)에 있습니다. XLAM 단독형은 추가 기능 목록에서 체크를 해제하고 Excel을 종료한 뒤 파일을 제거합니다. EXE 설치형은 Windows의 설치된 앱 또는 같은 버전의 설치파일에서 제거할 수 있습니다.
