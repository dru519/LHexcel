# LHexcel 내엑셀

Windows Excel에서 표 그리기, 범위·시트 비교, 아래한글 표·그림 전송, 파일 통합 등을 돕는 추가 기능입니다. **소스 공개 소프트웨어**이며, 이용 조건은 [LICENSE](LICENSE)를 따릅니다.

개인·기업·공공기관의 일반 업무 사용은 무료입니다. 프로그램·소스의 판매, 유료 재배포, 상품화 및 유료 제품·서비스 포함은 금지합니다. 원본 무료 공유에는 출처와 이용 조건을 유지해야 하며, 수정본의 외부 배포에는 별도 허락이 필요합니다.

## 다운로드

[공식 Releases](https://github.com/dru519/LHexcel/releases)에서 파일과 SHA-256 목록을 확인하세요. 배포 파일은 단일 XLAM과 EXE 설치파일 두 가지입니다. DLL ZIP은 EXE를 구성하는 내부 패키지입니다. 현재 기능 기준은 **v0.01_r105**, 사용기한은 **2027-12-31**입니다.

| 파일 | 용도 |
|---|---|
| `LHexcel_v0.01_r105.xlam` | 별도 DLL·설치파일 없이 단일 파일로 사용 |
| `LHexcel_v0.01_r105_Setup.exe` | DLL 패키지를 포함하는 Windows 설치파일 |

설치 방법은 [XLAM·EXE 설치 안내](INSTALLING.md)에 있습니다. 설치판의 문서 비교와 아래한글 표·그림 전송에는 DLL 연결이 필요합니다. [DLL 설치 안내](06_개편소스/v0.01/docs/dll-install-guide.md)는 내부 패키지의 수동 설치·복구 절차입니다. 전자서명과 소속 조직의 실행 허용은 별도이며, 조직의 보안 정책에 따라 사용하세요.

## 공개 소스

- 제품 소스: `06_개편소스/v0.01/src` — VBA·폼·리본·자체 DLL·설치기
- 빌드 및 배포: `06_개편소스/v0.01/build`, `tools`
- 동작 계약과 검증 자료: `contracts`, 검토한 더미 테스트 자료
- 빌드 안내: [BUILDING.md](BUILDING.md)

공개 사본에는 개발 Git 이력, 인증정보, 서명키 저장소, 개인·내부 자료 및 개발 산출물을 포함하지 않습니다. 개인 알림 설정은 공개 기본값으로 바꾸었습니다. `PUBLIC_EXPORT.json`은 원본과 공개 파일의 해시 및 변경 범위를 기록합니다. `PUBLIC_SOURCE_SHA256SUMS`로 공개 파일을 검증할 수 있습니다.

r105의 기존 Windows 검증 기록을 기준으로 공개 패키지를 구성했습니다. 이번 공개 과정의 변경·파일 검사와 기존 기능 검증의 범위는 [릴리스 기록](RELEASE.md)에 구분하여 표시합니다.

문의는 [Issues](https://github.com/dru519/LHexcel/issues)를 이용해 주세요. 실사용 파일·개인정보·인증정보를 공개 글에 올리지 마세요.
