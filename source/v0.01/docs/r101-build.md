# 내엑셀 v0.01_r101 개발 검증

r101은 오류 안내를 한국어화하고 리본 오류를 수정했으며, 반복 처리 속도를 개선했습니다. 기능 목록 검증을 강화하고 아래한글 그림 전송을 포함합니다.

아래한글 그림 전송은 JPG·PNG·BMP를 문서에 포함한 셀 배경 그림으로 배치합니다. 기본 셀 크기는 7×6cm, 쪽당 가로 2개·세로 1개이며 제목행과 제목순·촬영시간순을 선택할 수 있습니다. 촬영시간 정보가 없는 파일은 뒤쪽에 제목순으로 배치합니다.

단일 XLAM은 DLL 없이 사용하고, DLL ZIP과 EXE는 고도화 기능을 포함합니다. 사용기한은 2027-12-31이며 2028-01-01부터 차단합니다.

서명과 조직 신뢰 승인 절차는 별도입니다. 생성·정렬·원본 보존·실제 Excel 검증과 한컴 렌더링 결과는 작업기록에서 구분하며, 네이티브 시험 통과 전 출시 완료로 표시하지 않습니다.
