# 내엑셀 v0.01_r103 검증 및 배포

아래한글 그림 전송의 제목행과 파일명 입력을 분리했습니다. 제목행을 추가한 뒤 ‘그림 파일명 넣기’를 해제하면 빈 제목칸만 생성합니다. 파일명은 확장자를 제외하며, 제목순·촬영시간순 정렬은 그대로 유지합니다. 제목행 없는 한 줄 그림의 내부망 생성 오류도 수정했습니다.

개인정보 검사 결과를 이름·생년월일·주민등록번호·연락처 중심으로 정리하고, 원본 셀 링크와 가려진 주민번호·이름 후보 인식 및 Esc 중단을 보완했습니다. 기호표의 단위·통화에는 면적·부피·길이·무게와 위 첨자 등 18개를 추가했습니다.

단일 XLAM, DLL 패키지 ZIP, EXE 설치파일을 같은 r103 소스로 생성합니다. 사용기한은 2027-12-31까지입니다. DLL 설치·연결 확인·제거 방법은 패키지 README에 포함합니다.

현재 전자서명은 적용하지 않았습니다. 보안 정책 우회를 안내하지 않습니다. 로컬 정적 검사나 백신 검사를 조직의 보안 승인·모든 PC의 안전성 보장으로 표시하지 않습니다. 실제 설치·제거 및 기능 검사 범위는 프로젝트 출시 기록을 확인하세요.

서명과 조직 신뢰 승인 절차는 별도입니다. 네이티브 시험 통과 전 출시 완료로 표시하지 않습니다.
