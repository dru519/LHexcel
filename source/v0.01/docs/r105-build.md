# 내엑셀 v0.01_r105 검증 및 배포

시트 비교에 차이 목록과 기준·비교 사본 셀 이동 링크를 추가했습니다. 결과를 현재 파일의 새 시트에 추가할 때에도 링크의 시트 이름을 맞춥니다.

파일 통합에 한 시트·시트별·둘 다 모드를 제공합니다. 시트별 결과에는 목차 만들기를 선택할 수 있습니다. 목차에서 개별 시트로 이동하고 각 시트 A1에서 목차로 돌아옵니다. 목차 이동 행을 추가하여 기존 첫 행 내용을 보존합니다. 통합데이터에는 링크를 추가하지 않습니다.

사용기한은 2027-12-31까지입니다. 내부망 단일 XLAM, DLL ZIP, EXE 설치파일을 같은 소스에서 생성합니다. DLL 패키지 README에 설치·연결 확인·제거 방법을 포함합니다.

서명과 조직 신뢰 승인 절차는 별도입니다. 네이티브 시험 통과 전 출시 완료로 표시하지 않습니다. 전자서명은 적용되지 않았습니다. 실제 검증 및 설치·교체 범위는 출시 기록을 확인하세요.
