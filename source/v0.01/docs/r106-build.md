# 내엑셀 v0.01_r106 검증 및 배포

아래한글 표 전송의 다중 제목행과 합계행 서식 참조를 수정했습니다. 모든 제목 셀에 음영을 적용하고 마지막 제목행 아래에 이중실선을 표시합니다. 합계행을 선택하면 전체 셀에 음영과 위·아래 강조선을 적용합니다. 합계행과 숨긴 행 포함 옵션은 기본 해제입니다.

포커스셀 바깥 셀 음영 옵션, 조건부서식이 있는 표의 표 그리기, 같은 파일의 여러 창에서 서식 변경 시 창 유지 개선을 포함합니다.

사용기한은 2027-12-31까지입니다. 최종 배포물은 내부망용 단일 XLAM과 EXE 설치파일 2종입니다. DLL과 설치 안내는 EXE 내부 패키지에 포함합니다. DLL ZIP은 빌드 중간 산출물입니다.

실제 검증 범위와 파일 해시는 프로젝트 출시 기록을 확인하세요. 전자서명과 조직 신뢰 승인은 별도입니다.
