# 내엑셀 v0.01_r65 구성 및 확인 범위

승인 범위: DLL 문서·시트 탐색, 그림 미리보기, 대형 통합문서 비교의 측정 및 제한적 DLL 가속.

- 내부망은 기존 VBA 기능을 유지한다. 새 DLL 동작은 정확한 버전·계약·비트수 연결 확인 뒤에만 사용한다.
- 문서 탐색은 기능 찾기와 별도 왼쪽 CTP다. 실패 시 기존 VBA 탐색으로 돌아간다.
- 그림 미리보기는 원본 셀을 건드리지 않는다. FIT/ORIGINAL의 표시 결과는 실제 Excel 삽입과 별도 대조한다.
- 비교는 값·수식의 배열 처리에 우선 적용하며 병합·세부 서식 경로는 기존 엔진을 유지한다.
- 서명과 x86 Excel/혼합 DPI 검증은 이번 확인 환경에 포함하지 않는다.

## 이번 변경

- 문서 탐색: 자체 제작 고정·새로 고침·접기 아이콘, DPI 대응 클릭 영역, 문서/시트별 검색과 지우기, 선택 행과 수량 표시.
- 그림 미리보기: 파일 목록과 배치 영역 분리, FIT/ORIGINAL 설명, 파일과 대상 셀 요약, 명시적 확인·취소.
- 그림 선택: Excel의 선택 객체가 다시 생성되어도 실제 셀·그림으로 비교하고, 이미 같은 상태는 재설정하지 않는다.
- 그림 입력 및 실행계획·실행결과 창: 맑은 고딕 9pt 명시. 승인·미리보기·실행 및 복구 절차는 유지한다.

## 설치와 검증 경계

단일 XLAM은 DLL 없이 기존 VBA 기능으로 사용한다. DLL ZIP과 EXE는 같은 기능에 DLL 탐색·미리보기·비교 확장을 더한다. 별도의 내부망 보안 격리 바이너리를 의미하지 않는다. DLL 설치·연결 확인·제거 방법은 패키지 README를 따른다.

서명은 이번 범위에서 제외합니다. Authenticode/VBA signature는 NOT_RUN이며 조직 신뢰 승인은 HOLD입니다. 현재 확인 환경은 Windows 200%와 x64 Excel이며 x86 Excel·혼합 DPI 모니터·조직 신뢰 정책은 별도 확인 대상이다. 내부망 조건부서식 포커스셀과 클릭 전 첫 휠 입력의 기존 제한은 유지한다.

실제 출시 여부와 검증한 정확한 파일 해시는 버전별 작업기록·검증 영수증에 남긴다. 기존 r64 완성본과 배포본을 덮어쓰지 않는다.
