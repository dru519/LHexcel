# 내엑셀 v0.01_r67 구성 및 확인 범위

r66을 보존하고 Frame 분류 순서 계약 일치, 그림 실제 조작 확인, DLL 비교 결과 탐색을 진행한다.

- DLL 결과창은 기존 비교 보고서를 바꾸지 않는다. 전체/값/수식/서식/병합/시트 차이를 필터하고 이전·다음 차이, 기준·비교 원본으로 이동한다.
- 결과 목록은 Excel STA에서 복제한 일반 문자열이다. worker에서 Excel을 조작하지 않는다. UI 행 번호 대신 세션의 원래 index와 side만 전달한다.
- VBA는 원래 보고서·시트 객체, 원본 경로, 일반 값과 self-anchor를 다시 대조한 뒤 기존 안전 원본 이동을 호출한다. 보고서 변경/닫힘/재열기, 숨김 대상, 임의 경로·수식·URI는 안전 검사로 거부한다.
- 원본의 현재 내용이 비교 당시와 동일하다는 해시 보장은 하지 않는다. 원본은 읽기 전용으로 열며 기존에 열린 원본과 사용자 변경은 보존한다.
- 비교 성공과 결과창 연결 실패를 분리한다. DLL이 없거나 연결되지 않으면 기존 xlsx 보고서를 유지한다. 설치 ZIP·EXE의 새 COM 서비스 등록/백업/제거 목록은 함께 갱신한다.
- Frame의 계약과 실행값을 일치시키고 상대 순서·분류명은 유지한다. 원문 제품 통합 28건과 정적 계약 대조로 검증한다.

## 설치 및 검증 경계

서명은 이번 범위에서 제외합니다. Authenticode/VBA signature는 NOT_RUN, 조직 신뢰 승인은 HOLD입니다.

단일 XLAM / DLL ZIP / 설치 EXE 3종을 병행한다. DLL ZIP README에 설치·실행·연결 확인·제거 안내를 포함하고 최초 설치 후 Excel에서 자동 실행한다. 기존 버전 제거와 설정 보존을 실제 설치 시험으로 구분한다.

무서명 출시를 유지한다. 인증과 조직 신뢰, 실제 내부망 반입, Office x86, 혼합 DPI는 별도 환경의 검증 대상이다. 조건부서식 포커스셀·클릭 전 첫 휠의 수용한 기존 제한은 유지한다. 현재 완료 여부는 프로젝트 r67 작업기록과 최종 릴리스 영수증을 확인한다.
