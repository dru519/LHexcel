# 내엑셀 v0.01_r73

표 그리기 백업은 각 셀의 실제 서식 속성을 모두 읽고, 앞 셀과 완전히 같은 속성 묶음의 중복 생성을 줄입니다. 테마/RGB, 대각선, 혼합 서식 및 실패 시 복구를 검증합니다. 50열×1800행 후보 측정은 약 58~64초이며 최종 빌드 수치는 출시 검증 기록에 별도로 표시합니다.

설치 EXE의 제거는 캐시 DLL이 없어도 검증된 내장 메타데이터와 설치 기록을 기준으로 진행합니다. 남아 있는 파일과 COM 등록의 소유권을 확인하고 등록 백업을 보존합니다. 삭제 실패 시 제거 완료로 기록하지 않으며 사용자 설정을 유지합니다.

현재 기능 목록, 직접 실행 흐름 및 폼 검증 자료를 맞추었습니다. DLL ZIP에는 설치·실행·연결 확인·제거 안내를 포함합니다.

서명과 조직 신뢰 승인 절차는 별도입니다. 네이티브 시험 통과 전 출시 완료로 표시하지 않습니다. 실제 보안 제품에 의한 격리/접근 차단 복구는 시험용 누락 시나리오와 구분합니다.
