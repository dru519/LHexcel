# 내엑셀 v0.01_r75

고도화 배포본의 DLL 서비스 연결 전에 배포 당시의 SHA-256과 등록된 로컬 DLL을 대조한다. DLL의 누락·변경·버전 혼합 시 해당 연결을 중단한다. 내부망 단일 XLAM은 DLL 없는 실행을 유지한다.

고도화 배포본은 문서 비교 및 아래한글 변환에서 기존 DLL 구현을 사용하고, 중복된 VBA 비교 알고리즘과 HWPX PowerShell 실행·내장 스크립트를 포함하지 않는다. 내부망용 경로는 유지한다.

표그리기 복구 기록의 대상 범위 사전 검사와 동일 서식 비교를 개선한다. 50열 × 1,800행의 전후 성능과 복구 결과를 Windows Excel에서 비교한다.

단일 XLAM·DLL ZIP·EXE를 별도 폴더로 산출하며 DLL ZIP에는 설치·자동 실행·연결 확인·제거 안내를 포함한다. 기존 완성본과 배포본은 변경하지 않는다.

서명과 조직 신뢰 승인 절차는 별도입니다.
해시 검사는 파일 일치 여부를 확인하지만 게시자 인증이나 VBA 분석 방지를 보장하지 않는다. COM 추가 기능 자체의 선행 로드까지 차단하는 보호 로더는 이번 범위에 포함하지 않는다.

네이티브 시험 통과 전 출시 완료로 표시하지 않습니다.
조직 내부망 반입·보안제품 허용 및 전자서명은 별도 검증 사항이다.
