# 내엑셀 v0.01_r76

서명과 조직 신뢰 승인 절차는 별도입니다.
네이티브 시험 통과 전 출시 완료로 표시하지 않습니다.

고도화판은 NxHost 보호 로더가 NxCore 기능 모듈의 해시와 모듈 ID를 확인한 뒤
로드합니다. 내부망 단일 XLAM은 DLL 없이 작동하며 배포용 VBA의 내부 이름을
간소화했습니다. 실행에 필요한 VBA가 남으므로 소스 비공개를 보장하지 않습니다.

배포 사용기한은 RSA 서명과 문서 속성을 함께 확인합니다. 사용기한·보호장치의
임의 변경은 AI·자동화 도구를 이용한 경우에도 금지됩니다. 만료되거나 보호 정보가
잘못된 경우 내엑셀 관리 메뉴의 상태 안내·제거 기능만 사용할 수 있습니다.
외부 AI에 파일을 업로드하는 행위를 감지하거나 경고 표시를 강제하지는 못합니다.

발급용 개인 키는 빌드 PC 사용자의 Windows CSP에 보관되며 배포 파일에 포함하지
않습니다. 이 서명은 게시자 인증서 및 Excel의 신뢰할 수 있는 게시자 등록과 별개입니다.
확인 프로그램 자체가 교체된 경우까지 보호를 보장하지 않습니다.

표그리기는 조건에 맞는 연속 범위의 서식을 Excel의 임시 메모리 통합문서에
백업하고, 실패하면 복원한 뒤 임시 통합문서를 닫습니다. 원본 파일은 복제용
저장 경로에 쓰지 않습니다. 지원 조건 밖에서는 기존 복구 기록 방식을 사용합니다.

실제 Excel·설치·교체·성능 검증 결과와 지원 범위는 함께 제공한 출시 검증 기록을
확인하세요. 기존 r75 출시 파일은 보존합니다.
