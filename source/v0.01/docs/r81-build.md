# 내엑셀 v0.01_r81

표그리기에서 그림·차트가 있는 시트 및 서식으로 사용 범위가 늘어난 시트의 백업 성능을 개선합니다.
Excel의 시트 복사 기반 백업은 사용 범위 100만 셀 이하, 자동 도형·내장 그림·차트 합계 16개 이하에 적용합니다.
연결 그림·컨트롤·OLE 등은 기존 셀별 복구 경로를 유지합니다.
원본 데이터·개체·대상 밖 서식 보존 및 오류 복구를 검증합니다.

서명과 조직 신뢰 승인 절차는 별도입니다.
네이티브 시험 통과 전 출시 완료로 표시하지 않습니다.
이번 산출 범위는 완성본이며 배포본은 생성하지 않습니다.
