# 내엑셀 v0.01_r87 데이터 비교 완성본

데이터 비교 대분류에서 범위 비교·시트 비교를 실행합니다. 기준/비교 데이터는 새 통합문서 두 시트에 값 사본으로 생성되며 차이는 연한 빨강으로 표시합니다. 저장은 사용자가 결정합니다.

원본은 변경하지 않습니다. 위치 기준으로 비교하며 행 이동이나 정렬을 추론하지 않습니다. 수식 비교는 옵션입니다. 값 사본은 원본의 표 서식·도형·병합을 복제하지 않습니다.

이번 작업은 완성본만 생성합니다. 배포본·설치파일·메일 발송은 별도 요청 시 진행합니다. 상세 시험 결과는 프로젝트 업데이트 기록을 확인하세요.
