# 내엑셀 v0.01_r88 완성본

- 데이터 > 데이터 비교 > 범위 비교 / 시트 비교 / 파일 비교.
- 범위·시트 비교: 최대 100만 셀, 새 통합문서의 기준/비교 시트에 차이를 연한 빨강으로 표시.
- 파일 비교: 두 파일 전체 시트 비교, 값·수식·병합과 선택적 서식 비교, 차이 이동 링크가 있는 새 보고서. 기존 파일 엔진의 전체 20만 셀 한도를 유지.
- 실행 버튼을 누르면 바로 처리하며, 결과 파일 저장은 사용자가 선택한다.
- 내부망은 VBA 대체 엔진, 고도화판은 사용 가능한 DLL 연계 엔진을 이용한다.

완성본은 개발용이다. 보호 배포본은 별도 요청 시 생성한다.
게시자 서명 및 32비트 Excel 실기 검증은 포함하지 않는다.
