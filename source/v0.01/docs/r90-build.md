# 내엑셀 v0.01_r90

포커스셀 내부 좌표가 갱신되어도 화면은 이전 셀에 멈추는 문제를 수정했습니다.
선택 변경 시 활성 시트를 재계산하여 조건부서식 화면을 갱신합니다.
같은 범위 중복 갱신은 생략합니다. 부분 재계산과 화면 다시 그리기만으로는
실제 Excel 화면의 A1 고정 현상이 해결되지 않아 시트 재계산을 사용합니다.
수동 계산 모드 설정은 유지하지만 활성 시트의 화면 밖 수식도 재계산됩니다.
NOW 등 휘발성 수식 값이 바뀔 수 있으며, 수식이 많은 시트에서는 비용이 증가합니다.
다른 시트나 전체 통합문서의 재계산을 직접 요청하지는 않습니다.
이벤트 복구와 범위·시트·파일 비교는 r89에서 유지합니다.

조건부서식 엔진은 복사 중과 실행 취소가 남아 있는 편집 이후 강조 갱신을 보류합니다.
사용기한은 2027-12-31까지, 차단 시작은 2028-01-01입니다.
게시자 서명과 32비트 Excel 실기 검증은 별도입니다.
